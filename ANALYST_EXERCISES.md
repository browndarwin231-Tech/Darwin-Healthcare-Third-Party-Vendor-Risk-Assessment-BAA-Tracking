# Hands-On Analyst Exercises

1. **BAA decision:** Identify every vendor marked `PHI Access? = Yes` without a `Signed` BAA. Which vendor is marked `Blocked`, and why?
2. **Evidence triage:** Read `sample_evidence/vendor_questionnaire.csv`. Which claims lack sufficient support? Map each to an evidence request and risk finding.
3. **Risk scoring:** Confirm that ClinicBridge's score is 25 (Likelihood 5 × Impact 5) and explain why that does **not** by itself prove a HIPAA violation.
4. **Scope verification:** Evaluate the `analytics_data_flow.txt` excerpt. What follow-up questions would you ask to assess whether PHI is actually present?
5. **CISO communication:** Write a 150–200 word decision summary identifying the highest-priority vendor, evidence gap, assigned owner, and suggested next action.
6. **Closeout:** Simulate receiving an executed BAA for V-005. Update only the relevant register and finding fields, documenting the artifact reference and approval decision. Do not automatically close security risks merely because a BAA is signed.

Explain the difference between (a) vendor security assurance, (b) determining business associate status, and (c) confirming an executed BAA.
